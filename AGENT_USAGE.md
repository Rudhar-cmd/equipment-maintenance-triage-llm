# AGENT_USAGE

AI assistance was used for project scaffolding, UI/API implementation, validation, documentation, and test generation.

Human-review requirements implemented:
- deterministic threshold checks remain deterministic
- possible causes are not confirmed findings
- technician approval is required
- missing/conflicting sensor data is surfaced
- evidence is attached to recommendations
- AI/retrieval failures are explicit
- no remote equipment control
- no automatic maintenance approval
